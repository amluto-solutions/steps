IT 팀, 지원 데스크, 교육 담당자 등 사용 가이드를 쓰는 모든 분을 위한 앱입니다.

개인 정보 보호를 기본으로

• 가이드를 단계별로 재생하고, 오프라인에서도 작동하며, 간단한 목록으로 인쇄되는 대화형 웹 페이지.

• 공유 라이브러리, 회사 브랜드, 앱 언어, 녹화하지 않는 앱, 입력 내용 녹화 끄기를 그룹 정책과 Intune으로 설정할 수 있습니다. IT 가이드는 steps.amluto.com/it에 있습니다.

계정 없이 무료로 사용할 수 있습니다.

### Description

(Up to 16,000 characters.)

```
Steps는 브라우저에서 하는 작업을 단계별 가이드로 만들어 줍니다.

도구 모음에서 Steps를 열고 녹화 시작을 누른 다음 평소처럼 작업하세요. 클릭할 때마다 스크린샷과 “저장” 클릭 같은 문구가 있는 단계가 자동으로 작성됩니다. 녹화를 중지하면 가이드를 검토하세요. 문구를 고치고, 개인적인 내용은 흐리게 처리하고, 화살표와 상자, 메모를 넣고, 단계 순서를 바꾸거나 삭제할 수 있습니다. 그런 다음 PDF, Word 문서 또는 단계별로 재생되는 대화형 웹 페이지로 내보내거나, 메일, Teams, SharePoint에 복사해 넣으세요.

개인 정보 보호를 기본으로
• 녹화 중일 때만 녹화하며, 측면 패널에 녹화되는 단계가 바로 표시됩니다.
• 모든 내용은 브라우저나 선택한 폴더 등 컴퓨터에만 보관됩니다. 계정, 분석, 추적이 없으며 Amluto로 아무것도 보내지 않습니다.
• 입력 내용은 녹화할 때 “입력 내용 녹화”를 선택한 경우에만 녹화되며, 암호 상자나 비밀 정보가 담긴 필드에서는 절대 녹화되지 않습니다.
• 선택한 사이트는 절대 녹화되지 않습니다.
• 내보내기 전에 모든 스크린샷을 보여 주고, 흐리게 처리되지 않은 개인 정보일 수 있는 항목을 알려 줍니다.

내 언어로
Steps는 38개 언어를 지원하며 브라우저 언어나 설정에서 고른 언어를 따릅니다. 가이드 하나에 여러 언어를 담을 수 있고, 웹 페이지 내보내기는 읽는 사람의 언어로 열립니다.

조직용
IT 부서에서 모든 사용자에게 설치하고 Chrome 또는 Edge 정책으로 녹화하지 않는 사이트, 항상 흐리게 처리할 단어, 읽지 않을 추가 필드 이름, 언어, “입력 내용 녹화” 끄기를 설정할 수 있습니다.

Windows용 Steps 앱 사용자와 .amlsteps 파일로 가이드를 주고받거나, 함께 라이브러리로 쓰는 OneDrive 또는 SharePoint 폴더로 공유할 수 있습니다(Chrome 및 Edge).
```
