# Store listing texts: Latviešu (lv)

These are the Latvian translations of [en.md](en.md), to paste into each store's listing for Latvian. The headings and notes are in English; the text inside each block is what customers read.

## Microsoft Store

(Up to 10,000 characters.)

```

Nospiediet “Jauns ieraksts” un veiciet uzdevumu tā, kā vienmēr. Steps pieraksta katru klikšķi kā soli ar ekrānuzņēmumu un skaidru formulējumu, piemēram, Noklikšķiniet uz “Saglabāt”. Sakārtojiet pamācību, aizmiglojiet privāto informāciju, pievienojiet savu zīmolu un kopīgojiet to kā PDF, Word dokumentu vai interaktīvu tīmekļa lapu.

Izveidota IT komandām, atbalsta dienestiem, apmācītājiem un ikvienam, kas raksta pamācības.

PRIVĀTUMS JAU PAMATĀ
• Jūsu pamācības paliek jūsu datorā vai jūsu izvēlētajā mapē, piemēram, OneDrive vai SharePoint. Nav konta, nav analītikas, un nekas netiek sūtīts mums.
• E-pasta adreses, tālruņa numuri, pasta indeksi, karšu numuri, kā arī vārdi vai ID blakus to etiķetēm tiek atrasti katrā ekrānuzņēmumā jūsu datorā. Aizmiglojiet tos pa vienam vai visus uzreiz.
• Tas, ko ievadāt, tiek ierakstīts tikai tad, ja attiecīgajam ierakstam atzīmējat “Ierakstīt ievadīto tekstu”, un paroļu lauki netiek ierakstīti nekad.

PAMĀCĪBAS, KAS IZSKATĀS PABEIGTAS
• Pārformulējiet soļus, pievienojiet piezīmes un krāsainus padomu un brīdinājumu lodziņus, zīmējiet bultiņas un rāmjus, apgrieziet.
• Izvēlieties, kā soļi skan: neformāli, vienkāršā valodā vai formāli.
• Jūsu logotips, krāsas un fonti katrā eksportā, ar atsevišķu zīmolu katram klientam.
• PowerShell vai Windows Terminal ievadītās komandas kļūst par koda blokiem ar savu pogu “Kopēt”, un paroles un piekļuves marķieri tiek paslēpti.

JŪSU VALODĀ

• Interaktīva tīmekļa lapa, kas atskaņo pamācību soli pa solim, darbojas bezsaistē un tiek drukāta kā vienkāršs saraksts.

GATAVA IT NODAĻAI

Bezmaksas, bez konta.
```

## Chrome Web Store and Edge Add-ons

### Summary

(Up to 132 characters.)

```
Ierakstiet uzdevumu Chrome klikšķi pa klikšķim un pārvērtiet to pamācībā ar ekrānuzņēmumiem. Nekas neatstāj jūsu datoru.
```

### Description

(Up to 16,000 characters.)

```
Steps pārvērš pārlūkprogrammā veiktu uzdevumu soli pa solim pamācībā.

Atveriet Steps rīkjoslā, nospiediet “Sākt ierakstīšanu” un veiciet uzdevumu kā parasti. Katrs klikšķis kļūst par soli ar ekrānuzņēmumu un jūsu vietā uzrakstītiem vārdiem, piemēram, Noklikšķiniet uz “Saglabāt”. Kad apturat ierakstīšanu, pārskatiet pamācību: rediģējiet vārdus, aizmiglojiet privāto informāciju, pievienojiet bultiņas, rāmjus un piezīmes, mainiet soļu secību vai dzēsiet tos. Pēc tam eksportējiet to kā PDF, Word dokumentu vai interaktīvu tīmekļa lapu, kas atskaņo pamācību soli pa solim, vai kopējiet to e-pasta ziņojumā, Teams vai SharePoint.

Privātums jau pamatā
• Tas ieraksta tikai tad, kad jūs ierakstāt, un sānu panelī katrs solis tiek parādīts, tiklīdz tas ir ierakstīts.
• Viss paliek jūsu datorā: pārlūkprogrammā vai jūsu izvēlētajā mapē. Nav kontu, nav analītikas, nav izsekošanas, un nekas netiek sūtīts mums.
• Tas, ko ievadāt, tiek ierakstīts tikai tad, ja attiecīgajam ierakstam atzīmējat “Ierakstīt ievadīto tekstu”, un nekad no paroļu lodziņiem vai laukiem ar slepenu informāciju.
• Jūsu izvēlētās vietnes netiek ierakstītas nekad.
• Pirms jebkura eksporta tiek parādīti visi ekrānuzņēmumi un norādīti iespējamie neaizmiglotie personas dati.

Jūsu valodā
Steps runā 38 valodās un izmanto jūsu pārlūkprogrammas valodu vai to, ko izvēlaties iestatījumos. Pamācībā var būt teksti vairākās valodās, un eksportētā tīmekļa lapa atveras katra lasītāja valodā.

Organizācijām
IT nodaļa var instalēt paplašinājumu visiem un iestatīt izvēles, izmantojot Chrome vai Edge politikas: vietnes, kas nekad netiek ierakstītas, vārdus, kas vienmēr tiek aizmigloti, papildu lauku nosaukumus, kas nekad netiek nolasīti, valodu un opcijas “Ierakstīt ievadīto tekstu” izslēgšanu.

Pamācības var kopīgot ar Steps programmas Windows lietotājiem kā .amlsteps failus vai, izmantojot OneDrive vai SharePoint mapi, ko abi izmantojat kā bibliotēku (Chrome un Edge).
```
