# Store listing texts: Español (es)

These are the Spanish translations of [en.md](en.md), to paste into each store's listing for Spanish. The headings and the notes in brackets stay in English; the text inside each block is what customers read.

## Microsoft Store

### Description

(Up to 10,000 characters.)

```
Steps convierte una tarea que haces una vez en una guía paso a paso.

Pulsa Nueva grabación y haz la tarea como siempre. Steps anota cada clic como un paso con una captura de pantalla y un texto claro, como Haz clic en “Guardar”. Retócala, desenfoca lo privado, añade tu marca y compártela como PDF, documento de Word o página web interactiva.

Pensado para equipos de TI, servicios de soporte, formadores y cualquiera que escriba guías prácticas.

PRIVADO DESDE EL DISEÑO
• Tus guías se quedan en tu PC o en la carpeta que elijas, como OneDrive o SharePoint. Sin cuenta, sin análisis y sin enviarnos nada.
• Los correos electrónicos, números de teléfono, códigos postales, números de tarjeta, y los nombres o identificadores junto a sus etiquetas se detectan en cada captura, en tu PC. Desenfócalos de uno en uno o todos a la vez.
• Lo que escribes solo se graba si marcas “Grabar lo que se escribe” en esa grabación, y los campos de contraseña nunca se graban.

GUÍAS CON ACABADO PROFESIONAL
• Reformula pasos, añade notas y cuadros de color de sugerencia y advertencia, dibuja flechas y cuadros, y recorta.
• Elige cómo se leen los pasos: informal, lenguaje claro o formal.
• Tu logotipo, colores y fuentes en cada exportación, con una marca para cada cliente.
• Los comandos escritos en PowerShell o Windows Terminal se convierten en bloques de código con su propio botón Copiar, con las contraseñas y los tokens ocultos.

EN TU IDIOMA
• Steps habla 38 idiomas. Sigue el idioma de Windows o el que elijas en Configuración.
• Una guía puede tener su texto en varios idiomas: los pasos grabados se redactan automáticamente en cada uno, y tú escribes tus notas en cada uno.
• Exporta un PDF o un documento de Word en cualquiera de ellos, o una página web que se abre en el idioma de cada lector.

COMPÁRTELA A TU MANERA
• PDF, con un paso por página o varios.
• Word, con encabezados reales y texto alternativo en cada captura.
• Copia y pega en Outlook, Teams, SharePoint o Confluence.
• Una página web interactiva que reproduce la guía paso a paso, funciona sin conexión y se imprime como una lista sencilla.

PREPARADO PARA LOS EQUIPOS DE TI
• Configuración de directiva de grupo e Intune para bibliotecas compartidas, marcas de empresa, el idioma de la aplicación, aplicaciones que nunca se graban y desactivar la captura de lo que se escribe. La guía para TI está en steps.amluto.com/it.

Gratis y sin cuenta.
```

## Chrome Web Store and Edge Add-ons

### Summary

(Up to 132 characters.)

```
Graba una tarea en Chrome clic a clic y conviértela en una guía paso a paso con capturas. Nada sale de tu dispositivo.
```

### Description

(Up to 16,000 characters.)

```
Steps convierte una tarea que haces en el navegador en una guía paso a paso.

Abre Steps desde la barra de herramientas, pulsa Iniciar grabación y haz la tarea como siempre. Cada clic se convierte en un paso con una captura de pantalla y un texto como Haz clic en “Guardar”, escrito automáticamente. Cuando termines, revisa la guía: edita el texto, desenfoca lo privado, añade flechas, cuadros y notas, y reordena o elimina pasos. Después expórtala como PDF, documento de Word o página web interactiva que se reproduce paso a paso, o cópiala en un correo, en Teams o en SharePoint.

Privado desde el diseño
• Solo graba mientras estás grabando, y el panel lateral muestra cada paso a medida que se graba.
• Todo se queda en tu dispositivo: en tu navegador o en la carpeta que elijas. No hay cuentas, análisis ni seguimiento, y no se nos envía nada.
• Lo que escribes solo se graba si marcas “Grabar lo que se escribe” en esa grabación, y nunca en cuadros de contraseña ni en campos que contienen secretos.
• Los sitios que elijas nunca se graban.
• Antes de cualquier exportación, muestra cada captura y señala los posibles datos personales que no estén desenfocados.

En tu idioma
Steps habla 38 idiomas y sigue el idioma de tu navegador o el que elijas en Configuración. Una guía puede tener su texto en varios idiomas, y una exportación a página web se abre en el idioma de cada lector.

Para organizaciones
El departamento de TI puede instalarla para todos y establecer opciones mediante directivas de Chrome o Edge: sitios que nunca se graban, palabras que siempre se desenfocan, nombres de campo adicionales que nunca se leen, el idioma y la desactivación de “Grabar lo que se escribe”.

Las guías se pueden compartir con quienes usan la aplicación Steps para Windows como archivos .amlsteps, o mediante una carpeta de OneDrive o SharePoint que uses con ellos como biblioteca (en Chrome y Edge).
```
