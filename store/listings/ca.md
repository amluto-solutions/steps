# Store listing texts: Català (ca)

These are the Catalan translations of [en.md](en.md), to paste into each store's listing for Catalan. The headings and notes stay in English; the text inside each block is what customers read.

## Microsoft Store

### Description

(Up to 10,000 characters.)

```
Steps converteix una tasca que feu una vegada en una guia pas a pas.

Premeu Enregistrament nou i feu la tasca com ho feu sempre. Steps anota cada clic com un pas amb una captura de pantalla i un text senzill, com ara Fer clic a «Desa». Poliu la guia, difumineu qualsevol cosa privada, afegiu-hi la vostra marca i compartiu-la com a PDF, document del Word o pàgina web interactiva.

Pensat per a equips d'informàtica, serveis d'assistència, formadors i tothom qui escriu guies pràctiques.

PRIVADESA DES DEL DISSENY
• Les guies es queden al vostre PC o a la carpeta que trieu, com ara el OneDrive o el SharePoint. Sense compte, sense analítiques i sense enviar-nos res.
• Els correus electrònics, els números de telèfon, els codis postals, els números de targeta i els noms o identificadors al costat de la seva etiqueta es detecten a cada captura de pantalla, al vostre PC. Difumineu-los d'un en un o tots alhora.
• El que escriviu només s'enregistra si marqueu «Enregistra el que s'escriu» en aquell enregistrament, i els camps de contrasenya no s'enregistren mai.

GUIES AMB ACABAT PROFESSIONAL
• Torneu a redactar els passos, afegiu-hi notes i requadres de color de consell i advertiment, dibuixeu-hi fletxes i requadres, i retalleu.
• Trieu com es llegeixen els passos: informal, llenguatge planer o formal.
• El vostre logotip, colors i tipus de lletra a cada exportació, amb una marca per a cada client.
• Les ordres escrites al PowerShell o al Windows Terminal es converteixen en blocs de codi amb el seu propi botó Copia, i les contrasenyes i els testimonis queden emmascarats.

EN LA VOSTRA LLENGUA
• Steps parla 38 idiomes. Segueix l'idioma del Windows, o el que trieu a la Configuració.
• Una guia pot tenir el text en diversos idiomes: els passos enregistrats es redacten automàticament en cadascun, i hi podeu escriure les vostres notes en cada idioma.
• Exporteu un PDF o un document del Word en qualsevol d'aquests idiomes, o una pàgina web que s'obre en l'idioma de cada lector.

COMPARTIU-LA COM VULGUEU
• PDF, amb un pas per pàgina o diversos.
• Word, amb títols reals i text alternatiu a cada captura de pantalla.
• Copieu i enganxeu a l'Outlook, el Teams, el SharePoint o el Confluence.
• Una pàgina web interactiva que reprodueix la guia pas a pas, funciona sense connexió i s'imprimeix com una llista senzilla.

A PUNT PER AL DEPARTAMENT D'INFORMÀTICA
• Configuració de Directiva de grup i d'Intune per a biblioteques compartides, marques de l'empresa, l'idioma de l'aplicació, aplicacions que no s'enregistren mai i la desactivació de la captura del text escrit. La guia per a informàtics és a steps.amluto.com/it.

Gratuït i sense compte.
```

## Chrome Web Store and Edge Add-ons

### Summary

(Up to 132 characters.)

```
Enregistreu una tasca al Chrome clic a clic i convertiu-la en una guia pas a pas amb captures. No surt res de l'ordinador.
```

### Description

(Up to 16,000 characters.)

```
Steps converteix una tasca que feu al navegador en una guia pas a pas.

Obriu Steps des de la barra d'eines, premeu Inicia l'enregistrament i feu la tasca com sempre. Cada clic es converteix en un pas amb una captura de pantalla i un text com ara Fer clic a «Desa», escrit automàticament. Quan atureu l'enregistrament, reviseu la guia: editeu el text, difumineu qualsevol cosa privada, afegiu-hi fletxes, requadres i notes, i reordeneu o suprimiu passos. Després exporteu-la com a PDF, document del Word o pàgina web interactiva que es reprodueix pas a pas, o copieu-la en un correu electrònic, al Teams o al SharePoint.

Privadesa des del disseny
• Només enregistra mentre esteu enregistrant, i el plafó lateral mostra cada pas a mesura que s'enregistra.
• Tot es queda a l'ordinador: al navegador o en una carpeta que trieu. Sense comptes, sense analítiques, sense seguiment i sense enviar-nos res.
• El que escriviu només s'enregistra si marqueu «Enregistra el que s'escriu» en aquell enregistrament, i mai als quadres de contrasenya ni als camps que contenen secrets.
• Els llocs que trieu no s'enregistren mai.
• Abans de qualsevol exportació, mostra totes les captures de pantalla i assenyala les possibles dades personals que no estan difuminades.

En la vostra llengua
Steps parla 38 idiomes i segueix l'idioma del navegador, o el que trieu a la Configuració. Una guia pot tenir el text en diversos idiomes, i una pàgina web exportada s'obre en l'idioma de cada lector.

Per a organitzacions
El departament d'informàtica la pot instal·lar per a tothom i definir opcions mitjançant directives del Chrome o de l'Edge: llocs que no s'enregistren mai, paraules que sempre es difuminen, noms de camps addicionals que no es llegeixen mai, l'idioma i la desactivació d'«Enregistra el que s'escriu».

Les guies es poden compartir com a fitxers .amlsteps amb persones que fan servir l'aplicació Steps per a Windows, o mitjançant una carpeta del OneDrive o del SharePoint que feu servir tots dos com a biblioteca (al Chrome i a l'Edge).
```
