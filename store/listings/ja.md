# Store listing texts: 日本語 (ja)

These are the Japanese translations of [en.md](en.md), to paste into each store's listing for Japanese. The headings and notes stay in English; the text inside each fenced block is what customers read.

## Microsoft Store

### Description

(Up to 10,000 characters.)

```
Steps は、一度行った作業を手順ガイドにします。

「新しい記録」を押して、いつもどおりに作業するだけです。Steps がクリックごとに、スクリーンショットとわかりやすい文言（例: 「保存」をクリック）付きのステップとして記録します。内容を整え、個人情報をぼかし、自社のブランドを加えて、PDF、Word 文書、インタラクティブな Web ページとして共有できます。

IT チーム、サポート デスク、トレーナーなど、手順書を作成するすべての人のためのアプリです。

【プライバシーを重視した設計】
• ガイドは PC 上、または OneDrive や SharePoint など選択したフォルダーに保存されます。アカウントは不要で、分析機能もなく、弊社に何かが送信されることはありません。
• メール アドレス、電話番号、郵便番号、カード番号のほか、ラベルの横にある氏名や ID を、すべてのスクリーンショットから PC 上で検出します。1 つずつ、またはまとめてぼかすことができます。
• 入力内容は、記録ごとに「入力内容を記録」をオンにした場合にのみ記録されます。パスワード フィールドが記録されることはありません。

【完成度の高いガイド】
• ステップの文言の変更、メモや色付きのヒント・警告ボックスの追加、矢印やボックスの描画、トリミングができます。
• ステップの文体を、カジュアル、わかりやすい表現、フォーマルから選べます。
• すべてのエクスポートに自社のロゴ、色、フォントを使用でき、クライアントごとにブランドを用意できます。
• PowerShell や Windows Terminal で入力したコマンドは、専用の「コピー」ボタン付きのコード ブロックになり、パスワードやトークンはマスクされます。

【日本語を含む 38 言語に対応】
• Steps は 38 言語に対応しています。Windows の言語、または「設定」で選択した言語で表示されます。
• 1 つのガイドに複数の言語の文言を保持できます。記録したステップは各言語で自動的に記述され、メモは言語ごとに記述できます。
• PDF や Word 文書をどの言語でもエクスポートできます。Web ページは、閲覧者それぞれの言語で開きます。

【好きな方法で共有】
• PDF: 1 ページに 1 ステップ、または複数ステップ。
• Word: 正式な見出し付きで、すべてのスクリーンショットに代替テキストを設定。
• Outlook、Teams、SharePoint、Confluence にコピーして貼り付け。
• ガイドをステップごとに再生するインタラクティブな Web ページ。オフラインで動作し、印刷するとシンプルな一覧になります。

【IT 部門にも対応】
• 共有ライブラリ、会社のブランド、アプリの言語、記録しないアプリ、入力内容の記録のオフを、グループ ポリシーと Intune で設定できます。IT 向けガイドは steps.amluto.com/it にあります。

無料で、アカウントも不要です。
```

### Description

(Up to 16,000 characters.)

```
Steps は、ブラウザーで行った作業を手順ガイドにします。

ツール バーから Steps を開き、「記録を開始」を押して、いつもどおりに作業してください。クリックごとに、スクリーンショットと文言（例: 「保存」をクリック）付きのステップが自動的に作成されます。記録を停止したらガイドを確認し、文言の編集、個人情報のぼかし、矢印・ボックス・メモの追加、ステップの並べ替えや削除を行います。その後、PDF、Word 文書、ステップごとに再生するインタラクティブな Web ページとしてエクスポートするか、メール、Teams、SharePoint にコピーできます。

【プライバシーを重視した設計】
• 記録するのは記録中だけです。記録された各ステップは、その都度サイド パネルに表示されます。
• すべてのデータは、ブラウザー内または選択したフォルダーなど、お使いのコンピューター上に保存されます。アカウント、分析、トラッキングは一切なく、弊社に何かが送信されることもありません。
• 入力内容は、記録ごとに「入力内容を記録」をオンにした場合にのみ記録されます。パスワード ボックスや秘密の情報を含むフィールドから記録されることはありません。
• 選択したサイトは記録されません。
• エクスポートの前に、すべてのスクリーンショットを表示し、ぼかされていない個人情報の可能性がある箇所を示します。

【日本語を含む 38 言語に対応】
Steps は 38 言語に対応し、ブラウザーの言語、または「設定」で選択した言語で表示されます。1 つのガイドに複数の言語の文言を保持でき、Web ページのエクスポートは閲覧者それぞれの言語で開きます。

【組織での利用】
IT 部門は、全員にインストールして、Chrome または Edge のポリシーで設定を管理できます: 記録しないサイト、常にぼかす語句、読み取らない追加のフィールド名、言語、「入力内容を記録」のオフ。

ガイドは、.amlsteps ファイルとして Windows 版 Steps アプリのユーザーと共有できます。また、ライブラリとして共用する OneDrive または SharePoint のフォルダーを通じて共有することもできます（Chrome と Edge）。
```
