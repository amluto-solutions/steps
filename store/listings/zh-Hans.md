## Microsoft Store

### Description

(Up to 10,000 characters.)

```
Steps 能把你做过一次的任务变成一份分步指南。

按“新建录制”，然后像平常一样完成任务。Steps 会把每次单击记录为一个步骤，附上截图和简明的文字说明，例如 单击“保存”。你可以整理指南、模糊处理隐私内容、添加品牌标识，然后以 PDF、Word 文档或交互式网页的形式共享。

专为 IT 团队、服务台、培训师以及所有编写操作指南的人打造。

隐私至上
• 你的指南保存在你的电脑上或你选择的文件夹中，例如 OneDrive 或 SharePoint。无需帐户，没有分析统计，也不会向我们发送任何内容。
• 在你的电脑上即可找出每张截图中的电子邮件地址、电话号码、邮政编码、卡号，以及标签旁边的姓名或证件号码。你可以逐个模糊，也可以一次性全部模糊。
• 只有在某次录制中勾选“记录键入内容”时，才会记录你键入的内容，并且绝不会记录密码字段。

指南看起来专业完整
• 改写步骤，添加备注以及彩色的提示和警告框，绘制箭头和方框，还可以裁剪。
• 选择步骤的措辞风格：简洁、通俗易懂或正式。
• 每次导出都使用你的徽标、颜色和字体，并可为每个客户设置专属品牌。
• 在 PowerShell 或 Windows Terminal 中键入的命令会变成带有“复制”按钮的代码块，密码和令牌会被遮盖。

支持你的语言
• Steps 支持 38 种语言。它跟随 Windows 使用的语言，也可以在“设置”中自行选择。
• 一份指南可以包含多种语言的文字：录制的步骤会自动用每种语言写好，你自己的备注也可以用每种语言分别撰写。
• 可以用其中任意一种语言导出 PDF 或 Word 文档，也可以导出网页，让每位读者以自己的语言打开。

按你的方式共享
• PDF，每页一个步骤或多个步骤。
• Word，带有真正的标题，并且每张截图都有替代文字。
• 复制并粘贴到 Outlook、Teams、SharePoint 或 Confluence 中。
• 交互式网页，逐步播放指南，可脱机使用，打印时为简洁的列表。

为 IT 准备就绪
• 可通过组策略和 Intune 设置共享指南库、公司品牌、应用语言、从不录制的应用，以及关闭键入内容记录。IT 指南位于 steps.amluto.com/it。

免费，无需帐户。
```

### Description

(Up to 16,000 characters.)

```
Steps 能把你在浏览器中完成的任务变成一份分步指南。

从工具栏打开 Steps，按“开始录制”，然后照常完成任务。每次单击都会成为一个步骤，附有截图和自动写好的文字说明，例如 单击“保存”。停止录制后，检查指南：编辑文字、模糊处理隐私内容、添加箭头、方框和备注，以及调整步骤顺序或删除步骤。然后将其导出为 PDF、Word 文档或可逐步播放的交互式网页，或者复制到电子邮件、Teams 或 SharePoint 中。

隐私至上
• 仅在你录制时才会记录，侧边栏会在录制每个步骤时将其显示出来。
• 所有内容都保留在你的电脑上：在你的浏览器中，或在你选择的文件夹中。没有帐户，没有分析统计，没有跟踪，也不会向我们发送任何内容。
• 只有在某次录制中勾选“记录键入内容”时，才会记录你键入的内容，并且绝不会从密码框或包含机密信息的字段中记录。
• 你选择的网站永远不会被录制。
• 每次导出前，它都会显示每张截图，并指出可能未模糊的个人信息。

支持你的语言
Steps 支持 38 种语言，跟随你的浏览器语言，也可以在“设置”中自行选择。一份指南可以包含多种语言的文字，网页导出会以每位读者自己的语言打开。

面向组织
IT 部门可以为所有人安装它，并通过 Chrome 或 Edge 策略设置选项：从不录制的网站、始终模糊的字词、额外的永不读取的字段名称、语言，以及关闭“记录键入内容”。

可以通过 .amlsteps 文件与使用 Steps Windows 应用的人共享指南，也可以通过你们共同用作指南库的 OneDrive 或 SharePoint 文件夹共享（在 Chrome 和 Edge 中）。
```
