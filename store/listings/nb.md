# Store listing texts: Norsk bokmål (nb)

These are the Norwegian Bokmål translations of [en.md](en.md), to paste into each store's listing for Norwegian. The headings and notes stay in English; the text inside each block is what customers read.

## Microsoft Store

### Description

(Up to 10,000 characters.)

```
Steps gjør en oppgave du utfører én gang, om til en trinnvis veiledning.

Trykk på Nytt opptak, og gjør oppgaven slik du alltid gjør. Steps skriver ned hvert klikk som et trinn med et skjermbilde og en enkel tekst, for eksempel Klikk på «Lagre». Rydd opp, slør alt som er privat, legg til merkevaren din, og del veiledningen som PDF, Word-dokument eller interaktiv nettside.

Laget for IT-avdelinger, brukerstøtte, kursholdere og alle som skriver veiledninger.

PERSONVERN FRA BUNNEN AV
• Veiledningene dine blir på PC-en din eller i mappen du velger, for eksempel OneDrive eller SharePoint. Ingen konto, ingen analyse, og ingenting sendes til oss.
• E-postadresser, telefonnumre, postnumre, kortnumre og navn eller ID-er ved siden av etikettene sine blir funnet i hvert skjermbilde, på PC-en din. Slør dem én om gangen eller alle på én gang.
• Det du skriver, tas bare opp når du merker av for «Ta opp det som skrives» for det aktuelle opptaket, og passordfelt tas aldri opp.

VEILEDNINGER SOM SER FERDIGE UT
• Formuler trinn på nytt, legg til merknader og fargede bokser med tips og advarsler, tegn piler og bokser, og beskjær.
• Velg hvordan trinnene skal lyde: uformelt, på klarspråk eller formelt.
• Logoen, fargene og skriftene dine på hver eksport, med en merkevare for hver kunde.
• Kommandoer som skrives i PowerShell eller Windows Terminal, blir kodeblokker med egen Kopier-knapp, der passord og tokener er maskert.

PÅ DITT SPRÅK
• Steps finnes på 38 språk. Appen følger språket Windows bruker, eller det du velger i Innstillinger.
• En veiledning kan ha teksten sin på flere språk: Trinn fra opptaket formuleres på hvert av dem for deg, og du skriver dine egne merknader på hvert språk.
• Eksporter en PDF eller et Word-dokument på hvilket som helst av dem, eller en nettside som åpnes på hver lesers eget språk.

DEL PÅ DIN MÅTE
• PDF, ett trinn per side eller flere.
• Word, med ekte overskrifter og alternativ tekst på hvert skjermbilde.
• Kopier og lim inn i Outlook, Teams, SharePoint eller Confluence.
• En interaktiv nettside som spiller av veiledningen trinn for trinn, fungerer uten nett og skrives ut som en enkel liste.

KLAR FOR IT
• Innstillinger for gruppepolicy og Intune for delte biblioteker, firmamerkevarer, appens språk, apper som aldri tas opp, og avslått opptak av inntasting. IT-veiledningen finnes på steps.amluto.com/it.

Gratis, uten konto.
```

## Chrome Web Store and Edge Add-ons

### Summary

(Up to 132 characters.)

```
Ta opp en oppgave i Chrome klikk for klikk, og gjør den om til en trinnvis veiledning med skjermbilder. Ingenting forlater PC-en.
```

### Description

(Up to 16,000 characters.)

```
Steps gjør en oppgave du utfører i nettleseren, om til en trinnvis veiledning.

Åpne Steps fra verktøylinjen, trykk på Start opptak, og gjør oppgaven som vanlig. Hvert klikk blir et trinn med et skjermbilde og en tekst som Klikk på «Lagre», skrevet for deg. Når du stopper, går du gjennom veiledningen: Rediger teksten, slør alt som er privat, legg til piler, bokser og merknader, og endre rekkefølgen på eller slett trinn. Eksporter den deretter som PDF, Word-dokument eller interaktiv nettside som spilles av trinn for trinn, eller kopier den inn i en e-post, Teams eller SharePoint.

Personvern fra bunnen av
• Den tar bare opp mens du tar opp, og sidepanelet viser hvert trinn etter hvert som det tas opp.
• Alt blir på datamaskinen din: i nettleseren eller i en mappe du velger. Det finnes ingen kontoer, ingen analyse og ingen sporing, og ingenting sendes til oss.
• Det du skriver, tas bare opp hvis du merker av for «Ta opp det som skrives» for det aktuelle opptaket, og aldri fra passordfelt eller felt som inneholder hemmeligheter.
• Nettsteder du velger, tas aldri opp.
• Før hver eksport vises alle skjermbilder, og mulige personopplysninger som ikke er sløret, blir pekt ut.

På ditt språk
Steps finnes på 38 språk og følger språket i nettleseren, eller det du velger i Innstillinger. En veiledning kan ha teksten sin på flere språk, og en nettsideeksport åpnes på hver lesers eget språk.

For organisasjoner
IT kan installere den for alle og styre valg gjennom policyer for Chrome eller Edge: nettsteder som aldri tas opp, ord som alltid sløres, ekstra feltnavn som aldri leses, språket, og avslåing av «Ta opp det som skrives».

Veiledninger kan deles med personer som bruker Steps-appen for Windows, som .amlsteps-filer, eller gjennom en OneDrive- eller SharePoint-mappe dere begge bruker som bibliotek (i Chrome og Edge).
```
