# Store listing texts: Ελληνικά (el)

The Greek translations of [en.md](en.md), to paste into each store's listing for Greek. The headings and notes stay in English; the text in each block is what customers read.

## Microsoft Store

### Description

(Up to 10,000 characters.)

```
Το Steps μετατρέπει μια εργασία που κάνετε μία φορά σε οδηγό βήμα προς βήμα.

Πατήστε Νέα εγγραφή και κάντε την εργασία όπως πάντα. Το Steps καταγράφει κάθε κλικ ως βήμα με στιγμιότυπο οθόνης και απλή διατύπωση, όπως Κλικ στο «Αποθήκευση». Τακτοποιήστε τον οδηγό, θολώστε ό,τι είναι ιδιωτικό, προσθέστε την επωνυμία σας και μοιραστείτε τον ως PDF, έγγραφο Word ή διαδραστική ιστοσελίδα.

Φτιαγμένο για ομάδες IT, τμήματα υποστήριξης, εκπαιδευτές και όποιον γράφει οδηγούς χρήσης.

ΙΔΙΩΤΙΚΟΤΗΤΑ ΗΔΗ ΑΠΟ ΤΟΝ ΣΧΕΔΙΑΣΜΟ
• Οι οδηγοί σας μένουν στον υπολογιστή σας ή στον φάκελο που επιλέγετε, όπως στο OneDrive ή στο SharePoint. Χωρίς λογαριασμό, χωρίς αναλύσεις, και τίποτα δεν στέλνεται σε εμάς.
• Διευθύνσεις email, αριθμοί τηλεφώνου, ταχυδρομικοί κώδικες, αριθμοί καρτών, καθώς και ονόματα ή αναγνωριστικά δίπλα στις ετικέτες τους εντοπίζονται σε κάθε στιγμιότυπο οθόνης, στον υπολογιστή σας. Θολώστε τα ένα ένα ή όλα μαζί.
• Ό,τι πληκτρολογείτε καταγράφεται μόνο όταν επιλέξετε «Καταγραφή πληκτρολόγησης» για τη συγκεκριμένη εγγραφή, και τα πεδία κωδικού πρόσβασης δεν καταγράφονται ποτέ.

ΟΔΗΓΟΙ ΜΕ ΕΠΑΓΓΕΛΜΑΤΙΚΗ ΕΜΦΑΝΙΣΗ
• Αναδιατυπώστε βήματα, προσθέστε σημειώσεις και χρωματιστά πλαίσια συμβουλών και προειδοποιήσεων, σχεδιάστε βέλη και πλαίσια και κάντε περικοπή.
• Επιλέξτε πώς διαβάζονται τα βήματα: σε ανεπίσημο ύφος, σε απλή γλώσσα ή σε επίσημο ύφος.
• Το λογότυπο, τα χρώματα και οι γραμματοσειρές σας σε κάθε εξαγωγή, με ξεχωριστή επωνυμία για κάθε πελάτη.
• Οι εντολές που πληκτρολογείτε στο PowerShell ή στο Windows Terminal γίνονται μπλοκ κώδικα με δικό τους κουμπί Αντιγραφή, με κρυμμένους τους κωδικούς πρόσβασης και τα tokens.

ΣΤΗ ΓΛΩΣΣΑ ΣΑΣ
• Το Steps μιλά 38 γλώσσες. Ακολουθεί τη γλώσσα των Windows ή αυτήν που επιλέγετε στις Ρυθμίσεις.
• Ένας οδηγός μπορεί να έχει το κείμενό του σε πολλές γλώσσες: τα καταγεγραμμένα βήματα διατυπώνονται αυτόματα σε καθεμία, και εσείς γράφετε τις δικές σας σημειώσεις σε κάθε γλώσσα.
• Εξαγάγετε PDF ή έγγραφο Word σε οποιαδήποτε από αυτές ή μια ιστοσελίδα που ανοίγει στη γλώσσα κάθε αναγνώστη.

ΜΟΙΡΑΣΤΕΙΤΕ ΤΟ ΟΠΩΣ ΘΕΛΕΤΕ
• PDF, με ένα βήμα ανά σελίδα ή περισσότερα.
• Word, με πραγματικές επικεφαλίδες και εναλλακτικό κείμενο σε κάθε στιγμιότυπο οθόνης.
• Αντιγραφή και επικόλληση στο Outlook, στο Teams, στο SharePoint ή στο Confluence.
• Μια διαδραστική ιστοσελίδα που αναπαράγει τον οδηγό βήμα προς βήμα, λειτουργεί χωρίς σύνδεση και εκτυπώνεται ως απλή λίστα.

ΕΤΟΙΜΟ ΓΙΑ ΤΟ ΤΜΗΜΑ IT
• Ρυθμίσεις Πολιτικής ομάδας και Intune για κοινόχρηστες βιβλιοθήκες, εταιρικές επωνυμίες, τη γλώσσα της εφαρμογής, εφαρμογές που δεν καταγράφονται ποτέ και την απενεργοποίηση της καταγραφής πληκτρολόγησης. Ο οδηγός για IT βρίσκεται στο steps.amluto.com/it.

Δωρεάν, χωρίς λογαριασμό.
```

```

• Επιλέξτε πολλούς οδηγούς για να τους μετακινήσετε, να τους αντιγράψετε ή να τους διαγράψετε μαζί ή για να τους συγχωνεύσετε σε έναν, ακόμα και ανάμεσα σε βιβλιοθήκες.
• Αποθηκεύστε μια νέα εγγραφή σε οποιαδήποτε βιβλιοθήκη με το βέλος δίπλα στην Αποθήκευση οδηγού.
```

## Chrome Web Store and Edge Add-ons

### Summary

(Up to 132 characters.)

```
Καταγράψτε μια εργασία στο Chrome κλικ προς κλικ και φτιάξτε οδηγό βήμα προς βήμα με στιγμιότυπα. Όλα μένουν στον υπολογιστή σας.
```

### Description

(Up to 16,000 characters.)

```
Το Steps μετατρέπει μια εργασία που κάνετε στο πρόγραμμα περιήγησης σε οδηγό βήμα προς βήμα.

Ανοίξτε το Steps από τη γραμμή εργαλείων, πατήστε Έναρξη εγγραφής και κάντε την εργασία όπως συνήθως. Κάθε κλικ γίνεται ένα βήμα με στιγμιότυπο οθόνης και λέξεις όπως Κλικ στο «Αποθήκευση», γραμμένες για εσάς. Όταν σταματήσετε, ελέγξτε τον οδηγό: επεξεργαστείτε το κείμενο, θολώστε ό,τι είναι ιδιωτικό, προσθέστε βέλη, πλαίσια και σημειώσεις και αλλάξτε τη σειρά των βημάτων ή διαγράψτε τα. Μετά εξαγάγετέ τον ως PDF, έγγραφο Word ή διαδραστική ιστοσελίδα που αναπαράγεται βήμα προς βήμα ή αντιγράψτε τον σε email, στο Teams ή στο SharePoint.

Ιδιωτικότητα ήδη από τον σχεδιασμό
• Καταγράφει μόνο όσο κάνετε εγγραφή και το πλαϊνό πλαίσιο δείχνει κάθε βήμα καθώς καταγράφεται.
• Όλα μένουν στον υπολογιστή σας: στο πρόγραμμα περιήγησης ή σε φάκελο που επιλέγετε. Χωρίς λογαριασμούς, χωρίς αναλύσεις και χωρίς παρακολούθηση, και τίποτα δεν στέλνεται σε εμάς.
• Ό,τι πληκτρολογείτε καταγράφεται μόνο αν επιλέξετε «Καταγραφή πληκτρολόγησης» για τη συγκεκριμένη εγγραφή, και ποτέ από πεδία κωδικού πρόσβασης ή πεδία που περιέχουν μυστικά.
• Οι ιστότοποι που επιλέγετε δεν καταγράφονται ποτέ.
• Πριν από κάθε εξαγωγή δείχνει κάθε στιγμιότυπο οθόνης και επισημαίνει πιθανά προσωπικά στοιχεία που δεν έχουν θολωθεί.

Στη γλώσσα σας
Το Steps μιλά 38 γλώσσες και ακολουθεί τη γλώσσα του προγράμματος περιήγησής σας ή αυτήν που επιλέγετε στις Ρυθμίσεις. Ένας οδηγός μπορεί να έχει το κείμενό του σε πολλές γλώσσες και μια εξαγωγή ιστοσελίδας ανοίγει στη γλώσσα κάθε αναγνώστη.

Για οργανισμούς
Το τμήμα IT μπορεί να το εγκαταστήσει για όλους και να ορίσει επιλογές μέσω των πολιτικών του Chrome ή του Edge: ιστότοπους που δεν καταγράφονται ποτέ, λέξεις που θολώνονται πάντα, επιπλέον ονόματα πεδίων που δεν διαβάζονται ποτέ, τη γλώσσα και την απενεργοποίηση της «Καταγραφής πληκτρολόγησης».

Οι οδηγοί μπορούν να μοιραστούν με όσους χρησιμοποιούν την εφαρμογή Steps για Windows ως αρχεία .amlsteps ή μέσω ενός φακέλου OneDrive ή SharePoint που χρησιμοποιείτε και οι δύο ως βιβλιοθήκη (στο Chrome και στο Edge).
```
