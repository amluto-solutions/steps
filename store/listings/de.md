## Microsoft Store

### Description

(Up to 10,000 characters.)

```
Steps macht aus einer Aufgabe, die Sie einmal erledigen, eine Schritt-für-Schritt-Anleitung.

Klicken Sie auf „Neue Aufnahme“, und erledigen Sie die Aufgabe wie immer. Steps hält jeden Klick als Schritt mit Screenshot und verständlichem Text fest, etwa „Speichern“ anklicken. Räumen Sie die Anleitung auf, zeichnen Sie Privates weich, fügen Sie Ihre Marke hinzu, und teilen Sie sie als PDF, Word-Dokument oder interaktive Webseite.

Gemacht für IT-Teams, Support, Trainer und alle, die Anleitungen schreiben.

PRIVAT VON GRUND AUF
• Ihre Anleitungen bleiben auf Ihrem PC oder in einem Ordner Ihrer Wahl, etwa in OneDrive oder SharePoint. Kein Konto, keine Analysen, und nichts wird an uns gesendet.
• E-Mail-Adressen, Telefonnummern, Postleitzahlen, Kartennummern sowie Namen oder IDs neben ihren Beschriftungen werden in jedem Screenshot gefunden, direkt auf Ihrem PC. Zeichnen Sie sie einzeln oder alle auf einmal weich.
• Was Sie eingeben, wird nur aufgezeichnet, wenn Sie für diese Aufnahme „Eingaben aufzeichnen“ aktivieren, und Kennwortfelder nie.

ANLEITUNGEN, DIE FERTIG AUSSEHEN
• Schritte umformulieren, Notizen und farbige Tipp- und Warnkästen hinzufügen, Pfeile und Rechtecke zeichnen und zuschneiden.
• Wählen Sie, wie Schritte klingen: knapp, in einfacher Sprache oder formell.
• Ihr Logo, Ihre Farben und Schriftarten in jedem Export, mit einer eigenen Marke für jeden Kunden.
• In PowerShell oder Windows Terminal eingegebene Befehle werden zu Codeblöcken mit eigener Kopieren-Schaltfläche, und Kennwörter und Token werden maskiert.

IN IHRER SPRACHE
• Steps gibt es in 38 Sprachen. Es folgt der Sprache von Windows oder der Sprache, die Sie in den Einstellungen wählen.
• Eine Anleitung kann ihre Texte in mehreren Sprachen enthalten: Aufgezeichnete Schritte werden in jeder davon für Sie formuliert, und Ihre eigenen Notizen schreiben Sie in jeder Sprache selbst.
• Exportieren Sie ein PDF oder Word-Dokument in jeder dieser Sprachen oder eine Webseite, die sich in der Sprache des jeweiligen Lesers öffnet.

TEILEN, WIE SIE MÖCHTEN
• PDF, ein Schritt pro Seite oder mehrere.
• Word, mit echten Überschriften und Alternativtext zu jedem Screenshot.
• Kopieren und in Outlook, Teams, SharePoint oder Confluence einfügen.
• Eine interaktive Webseite, die die Anleitung Schritt für Schritt abspielt, offline funktioniert und sich als einfache Liste drucken lässt.

BEREIT FÜR DIE IT
• Gruppenrichtlinien- und Intune-Einstellungen für freigegebene Bibliotheken, Firmenmarken, die Sprache der App, nie aufgezeichnete Apps und das Abschalten der Eingabeaufzeichnung. Den IT-Leitfaden finden Sie unter steps.amluto.com/it.

Kostenlos und ohne Konto.
```

## Chrome Web Store and Edge Add-ons

### Summary

(Up to 132 characters.)

```
Zeichnen Sie eine Aufgabe in Chrome Klick für Klick auf: Daraus wird eine Anleitung mit Screenshots. Nichts verlässt Ihren PC.
```

### Description

(Up to 16,000 characters.)

```
Steps macht aus einer Aufgabe, die Sie im Browser erledigen, eine Schritt-für-Schritt-Anleitung.

Öffnen Sie Steps über die Symbolleiste, klicken Sie auf „Aufnahme starten“, und erledigen Sie die Aufgabe wie gewohnt. Jeder Klick wird zu einem Schritt mit Screenshot und einem Text wie „Speichern“ anklicken, für Sie geschrieben. Wenn Sie die Aufnahme beenden, prüfen Sie die Anleitung: Texte bearbeiten, Privates weichzeichnen, Pfeile, Rechtecke und Notizen hinzufügen und Schritte umsortieren oder löschen. Exportieren Sie sie dann als PDF, Word-Dokument oder interaktive Webseite, die Schritt für Schritt abläuft, oder kopieren Sie sie in eine E-Mail, Teams oder SharePoint.

Privat von Grund auf
• Steps zeichnet nur auf, während Sie aufzeichnen, und die Seitenleiste zeigt jeden Schritt, sobald er aufgezeichnet ist.
• Alles bleibt auf Ihrem Computer: in Ihrem Browser oder in einem Ordner Ihrer Wahl. Es gibt keine Konten, keine Analysen und kein Tracking, und nichts wird an uns gesendet.
• Was Sie eingeben, wird nur aufgezeichnet, wenn Sie für diese Aufnahme „Eingaben aufzeichnen“ aktivieren, und nie aus Kennwortfeldern oder Feldern mit vertraulichen Daten.
• Websites, die Sie auswählen, werden nie aufgezeichnet.
• Vor jedem Export zeigt Steps jeden Screenshot und weist auf mögliche persönliche Angaben hin, die nicht weichgezeichnet sind.

In Ihrer Sprache
Steps gibt es in 38 Sprachen. Es folgt der Sprache Ihres Browsers oder der Sprache, die Sie in den Einstellungen wählen. Eine Anleitung kann ihre Texte in mehreren Sprachen enthalten, und ein Webseiten-Export öffnet sich in der Sprache des jeweiligen Lesers.

Für Organisationen
Die IT kann die Erweiterung für alle installieren und Vorgaben über Chrome- oder Edge-Richtlinien festlegen: nie aufgezeichnete Websites, immer weichgezeichnete Wörter, zusätzliche Feldnamen, die nie gelesen werden, die Sprache und das Abschalten von „Eingaben aufzeichnen“.

Anleitungen lassen sich mit Nutzern der Steps-App für Windows als .amlsteps-Dateien teilen oder über einen OneDrive- oder SharePoint-Ordner, den Sie beide als Bibliothek verwenden (in Chrome und Edge).
```
