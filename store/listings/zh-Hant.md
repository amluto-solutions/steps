These are the Traditional Chinese (Taiwan) translations of [en.md](en.md), to paste into each store's listing for Traditional Chinese (zh-Hant). Headings and notes stay in English; the text in each block is what customers read.

## Microsoft Store

### Description

(Up to 10,000 characters.)

```
Steps 能把您做過一次的工作變成一份逐步指南。

按「新增錄製」，然後像平常一樣完成工作。Steps 會將每次點按記錄為一個步驟，附上螢幕擷取畫面和淺顯的文字說明，例如 按一下「儲存」。您可以整理指南、模糊處理私人內容、加上您的品牌，然後以 PDF、Word 文件或互動式網頁分享。

專為 IT 團隊、服務台、講師，以及所有撰寫操作指南的人打造。

隱私至上
• 您的指南保存在您的電腦上，或您選擇的資料夾中，例如 OneDrive 或 SharePoint。不需要帳戶、沒有分析統計，也不會傳送任何內容給我們。
• 在您的電腦上就能找出每張螢幕擷取畫面中的電子郵件地址、電話號碼、郵遞區號、卡號，以及標籤旁的姓名或證件號碼。您可以逐一模糊處理，也可以一次全部處理。
• 只有在某次錄製勾選「記錄輸入內容」時，才會記錄您輸入的內容，而且絕不記錄密碼欄位。

完成度十足的指南
• 改寫步驟、加上附註和彩色的提示與警告方塊、繪製箭號和方框，還能裁剪。
• 選擇步驟的措辭風格：簡潔、淺白易懂或正式。
• 每次匯出都使用您的標誌、色彩和字型，還能為每個客戶設定專屬品牌。
• 在 PowerShell 或 Windows Terminal 中輸入的命令會變成附有「複製」按鈕的程式碼區塊，密碼和權杖會被遮蔽。

支援您的語言
• Steps 支援 38 種語言。它會跟隨 Windows 使用的語言，您也可以在「設定」中自行選擇。
• 一份指南可以包含多種語言的文字：錄製的步驟會自動以每種語言寫好，您也可以用每種語言撰寫自己的附註。
• 可以用其中任何一種語言匯出 PDF 或 Word 文件，也可以匯出網頁，讓每位讀者以自己的語言開啟。

依您的方式分享
• PDF，每頁一個步驟或多個步驟。
• Word，含有真正的標題，且每張螢幕擷取畫面都有替代文字。
• 複製並貼到 Outlook、Teams、SharePoint 或 Confluence 中。
• 互動式網頁，可逐步播放指南、離線使用，列印時則是簡潔的清單。

為 IT 做好準備
• 可透過群組原則和 Intune 設定共用指南庫、公司品牌、應用程式語言、永不錄製的應用程式，以及關閉輸入內容記錄。IT 指南位於 steps.amluto.com/it。

免費，不需要帳戶。
```

### Description

(Up to 16,000 characters.)

```
Steps 能把您在瀏覽器中完成的工作變成一份逐步指南。

從工具列開啟 Steps，按「開始錄製」，然後照常完成工作。每次點按都會成為一個步驟，附有螢幕擷取畫面和自動寫好的文字說明，例如 按一下「儲存」。停止錄製後，檢查指南：編輯文字、模糊處理私人內容、加上箭號、方框和附註，以及調整步驟順序或刪除步驟。然後將它匯出為 PDF、Word 文件或可逐步播放的互動式網頁，或是複製到電子郵件、Teams 或 SharePoint 中。

隱私至上
• 只在您錄製時才會記錄，側邊面板會在錄製每個步驟時將它顯示出來。
• 所有內容都留在您的電腦上：在您的瀏覽器中，或您選擇的資料夾中。沒有帳戶、沒有分析統計、沒有追蹤，也不會傳送任何內容給我們。
• 只有在某次錄製勾選「記錄輸入內容」時，才會記錄您輸入的內容，而且絕不會從密碼方塊或存放機密資訊的欄位記錄。
• 您選擇的網站永遠不會被錄製。
• 每次匯出前，它都會顯示每張螢幕擷取畫面，並指出可能尚未模糊處理的個人資訊。

支援您的語言
Steps 支援 38 種語言，會跟隨您瀏覽器的語言，您也可以在「設定」中自行選擇。一份指南可以包含多種語言的文字，網頁匯出則會以每位讀者自己的語言開啟。

適用於組織
IT 部門可以為所有人安裝它，並透過 Chrome 或 Edge 原則設定選項：永不錄製的網站、一律模糊處理的字詞、額外的永不讀取欄位名稱、語言，以及關閉「記錄輸入內容」。

可以透過 .amlsteps 檔案與使用 Steps Windows 應用程式的人分享指南，也可以透過雙方共同作為指南庫使用的 OneDrive 或 SharePoint 資料夾分享（在 Chrome 和 Edge 中）。
```

### Description

(No limit that matters. The Chrome description, for Firefox.)

```

隱私至上
• 只在您錄製時才會記錄，側邊欄會在錄製每個步驟時將它顯示出來。
• 所有內容都留在您的電腦上，在您的瀏覽器中。沒有帳戶、沒有分析統計、沒有追蹤，也不會傳送任何內容給我們。
• 只有在某次錄製勾選「記錄輸入內容」時，才會記錄您輸入的內容，而且絕不會從密碼方塊或存放機密資訊的欄位記錄。
• 您選擇的網站永遠不會被錄製。
• 每次匯出前，它都會顯示每張螢幕擷取畫面，並指出可能尚未模糊處理的個人資訊。

支援您的語言
Steps 支援 38 種語言，會跟隨您瀏覽器的語言，您也可以在「設定」中自行選擇。一份指南可以包含多種語言的文字，網頁匯出則會以每位讀者自己的語言開啟。

```
