# Security

## Reporting a vulnerability

Please email **security@amluto.com** with:
- what you found
- the version of Amluto Steps
- how to reproduce it

Don't open a public issue for security problems.

We acknowledge reports within **5 working days**, keep you updated while we fix it, and credit you in the release notes if you'd like. Fixed versions are listed in the release notes.

## Scope

- Steps for Windows (Microsoft Store, setup `.exe`, `.msi`, portable program and winget)
- Steps for Linux (beta: `.deb` and AppImage)
- Steps for Chrome and Edge, and for Firefox
- The files they read and write: guides, `.amlsteps`, `.amlbrand`, `.amlsettings` and `.amlbackup`

What the app captures, and how it's protected, is described in the privacy policy at https://privacy.amluto.com/.
